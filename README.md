# Lawyer Booking System

A Django web application where clients can search lawyers by specialization and book appointments online.

### Features
- Separate Login for Client & Lawyer
- Search lawyers by specialization / location
- Appointment booking & availability management
- Razorpay payment gateway integration
- Dashboard for both users

### Tech Used
Python, Django, HTML, CSS, SQLite, Razorpay

### Run Locally
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
